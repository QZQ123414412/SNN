# 文档目录

```text
docs/
├─ methodology/             方法、指标定义和实验协议
├─ results/
│  ├─ regular/              常规准确率实验
│  ├─ spike_stats/          SOPs、脉冲率和稀疏率实验
│  └─ state_ftbc/           状态条件低秩 FTBC 正式结果
├─ design/                  pipeline 和创新方法设计
├─ archive/
│  ├─ state_ftbc/           冒烟、调优和中间实验
│  └─ project_history/      早期修改记录
└─ superpowers/plans/       实施计划
```

论文引用应优先使用 `results/` 下的结果。`archive/` 仅用于复盘实现过程，不应直接作为最终实验表格来源。
