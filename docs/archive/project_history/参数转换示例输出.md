## 关键变化说明

### 变化内容
- **每个阈值参数都新增了对应的负阈值**
- 正阈值保持不变
- 负阈值 = -正阈值

### 变化原因
- `IF` 神经元只需要一个正阈值
- `SignedIF` 神经元需要正负两个阈值
- 实现双向脉冲编码

### 示例
```
原始:
  layer1.0.thresh = 4.123456

转换后:
  layer1.0.thresh     = +4.123456  (正阈值，保持不变)
  layer1.0.neg_thresh = -4.123456  (负阈值，新增，取负值)
```

### 参数统计
| 类型 | 原始数量 | 转换后数量 | 变化 |
|------|---------|-----------|------|
| 阈值参数 | 16 | 32 | +16 (每个阈值增加1个负阈值) |
| 权重参数 | 26 | 26 | 不变 |
| 偏置参数 | 26 | 26 | 不变 |
| **总计** | **150** | **166** | **+16** |
